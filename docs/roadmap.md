# DiabetesCare — Roadmap

## Version 1.0 (Current)
- [x] Dashboard with live BG chart
- [x] Blood glucose logger
- [x] Insulin dose calculator
- [x] Insulin injection logger
- [x] Meal planner and carb counter
- [x] South African food database
- [x] 7-day insights and time in range
- [x] Settings with adjustable thresholds
- [x] Dark mode support
- [x] Responsive mobile design
- [x] GitHub Pages deployment

## Version 1.1 (Next)
- [ ] LocalStorage persistence — save data between browser sessions
- [ ] Export to CSV — download all readings as a spreadsheet
- [ ] Medication tracker — log tablets (metformin, etc.)
- [ ] Exercise log — track physical activity and BG impact

## Version 1.2
- [ ] PDF report generator — print-ready summary for doctor visits
- [ ] HbA1c history chart — track estimated A1c over time
- [ ] Expanded food database — 50+ South African and African foods
- [ ] Meal history — save and reuse favourite meal combinations

## Version 2.0
- [ ] PWA (Progressive Web App) — install to home screen, offline support
- [ ] Push notifications — BG reminder alerts
- [ ] CGM data import — support for Libre and Dexcom CSV exports
- [ ] Multi-language — isiZulu, Afrikaans, Sesotho, isiXhosa
- [ ] Doctor's report — formatted PDF for clinic visits
- [ ] Cloud sync — optional account for cross-device data
